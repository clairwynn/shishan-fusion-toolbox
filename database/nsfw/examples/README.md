# 示例库存档说明

本目录是**原文存档**：全部示例逐字来自内部模板素材，原样保留，未做改写。

**使用规则（重要）**：

- 示例中的历史写法**不代表本 skill 的输出规范**——包括但不限于：质量前缀（masterpiece / best quality / ultra detailed / 8k / photorealistic 等一律不写）、年代词、下划线拼写（本 skill 统一空格形态）、分级标签（safe / sensitive / nsfw / explicit / `rating:*`——本 skill 输出不写分级标签）。
- 参考或改编示例时，先剥离这些历史元素，再按 references/ 各规范产出。
- 成人语境中的服装元素（校服等）按 references/nsfw/themes.md 的校园条款执行：成年角色扮演框架 + 非青年化设定用语；所有角色均为成年人（core.md 总则）。
- 示例中的 `[图案]` `[位置]` 等方括号是填空占位符，使用时替换为具体内容。
