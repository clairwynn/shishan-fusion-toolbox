# 主题索引与极端主题门控

本文件有两部分：一是**极端主题清单与门控规则**（B 模式下必须遵守），二是**中文模板分册索引**（数据库素材导航）。

## 一、极端主题门控

**核心规则：以下主题只有在用户显式点名时才写。绝不从模糊的成人需求（如「来个NSFW」「画个涩图」）里自动选用其中任何一项。** 一个要求绳子、拍打、啃咬、粗暴、怪物或恐怖氛围的请求，本身不是添加 gore、死亡、动物、酷刑、处刑或 vore 的许可。

路由边界：

```
普通成人请求 → 默认成人分类，直接写
显式的受限主题请求 → 只写被请求的受限主题
显式的极端主题请求 → 只写被请求的极端主题
```

受限主题不替代姿势力学：校园场景、家庭关系、NTR 前提、催眠状态、非自愿框架或 fantasy 伴侣仍然需要具体的动作、接触图、环境与光源。

### Never-Auto-Select 清单（点名才写）

- 成人乱伦
- 教师/学生或校园角色扮演
- NTR 或出轨
- 有可见旁观者的偷窥
- 催眠、睡眠、下药、意识受损
- 非自愿或强迫
- fantasy 非人类插入
- 群交
- 兽交或动物性接触
- 尸体或恋尸主题
- gore、肢解、R18G 或重伤
- 酷刑或处刑
- 排泄物与排尿系（scat / urination 等，含 `database/nsfw/codex/gated/r18g/scat.md`）
- vore 或吞食

### 各主题的保留与边界规则

**成人校园/制服角色扮演**：允许大学课堂/宿舍/社团/图书馆/健身房/办公室、教师/教授/职员/研究生、制服角色扮演、大学教室式影棚重聚。用 university/campus 术语；年龄未指定的 student/teacher/家庭角色在内部归一为成年。

**成人乱伦**：年龄未指定的家庭角色条目可保留，家庭角色参与者在内部确认成年。正文角色示例：mother and son / father and daughter / two siblings / step-relatives。家庭角色的位置与身体归属独立于家庭角色写；除非被要求，不推断怀孕、breeding、强迫或年龄差。乱伦是 opt-in 的关系叠加层，不改变所选的物理行为。

**NTR/偷窥/被注视**：需要明确的关系与可见性逻辑——识别参与者、谁在场/观看/拍摄/缺席；区分自愿角色扮演、秘密出轨、偷窥与公共风险暴露；旁观者不露脸时用工线或拍摄设备建立存在，不发明画外之手；除非被要求，不加羞辱、强迫或额外参与者。

**催眠/睡眠/意识受损**：区分自愿角色扮演与非自愿虚构；通过眼睛、姿态、装置、摆锤、屏幕、耳机或睡眠场景在视觉上呈现状态；被催眠/睡眠的身体仍需有解剖支撑的姿势与清晰的身体归属；不自动加药物、束缚、插入或额外演员。

**成人非自愿/强迫虚构**：仅在显式请求后使用；不从眼泪、束缚、窘迫或粗暴动作单独推断。要求：清晰的参与者人数与角色归属、一个连贯行为而非堆叠虐待机制、稳定的身体支撑、可读的肢体归属。保持非自愿作为请求的叙事框架；不悄悄加酷刑、绑架、下药、群体侵犯或严重暴力。排除未成年人、动物、尸体、gore、残害或致命伤。

**Fantasy 非人类伴侣**：允许的人形家族——怪物、恶魔、兽人、史莱姆、触手、机械。fantasy 非人类默认受限；真实动物性素材属于单独的显式 opt-in 兽交类。规则：写明哪个附肢属于哪个生物/机械；绑定每次插入、束缚与液体来源；避免儿童化的妖精/幼态生物；除非明确要求多伴侣，一场景一个生物机制。

**极端类（全部仅限直接点名）**：

- **兽交**：保持真实动物的性接触，不重写成 kemonomimi/兽人/泛化 fantasy 生物；写明动物物种与接触归属；默认不与 fantasy 人形合并。
- **尸体/恋尸**：区分尸体、不死者人形、丧尸与摆拍角色扮演，不混同。
- **Gore/肢解/R18G**：独立的极端层。伤口、缺失肢体、血、暴露组织、破坏行为绑定到具体身体；不自动与无关性行为或道具组合。
- **酷刑与处刑**：写明装置、束缚、施加者、身体位置、可见后果；不把普通 impact play 悄悄升级。
- **Vore/吞食**：区分 oral vore、吞咽、内视概念、消化意象；不从普通的嘴或口交请求推断 vore。
