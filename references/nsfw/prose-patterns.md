# prose 场景模式库（自然语言流 B 模式：强度·玩法·玩具·骨架）

> prose-method.md 的配套模式库：那里是工作流（怎么写），这里是坐标系与素材（写多狠、写什么、从哪起笔）。强度阶梯同时服务 tag 流与 prose 流的档位判定。

## 一、强度阶梯（L1-L7，一图一档）

| 档 | 名称 | 内容边界 |
|---|---|---|
| **L1** | 暗示性着装 | 内衣/透视/敞袍/围裙等，情欲来自贴合度、透明度、姿态与视线；无露点要求 |
| **L2** | 裸体或半裸 | 胸/臀/生殖器可经全裸或褪衣可见；姿势情色，无玩具接触或性行为（`nude` 的默认档） |
| **L3** | 展露呈现 | 解剖无遮挡且刻意呈现（开展姿/镜/自拍/特写/公开风险），不自动加刺激或插入 |
| **L4** | 玩具预备/暗示 | 道具持近、藏衣下、架上就位、遥控在场——行为未开始（用户说「暗示/预备/即将」→ 此档） |
| **L5** | 外部刺激 | 手指/振动器/花洒/夹具/摩擦面明确接触：写归属+接触点+压力+可见反应；**不推断插入** |
| **L6** | 插入 | 假阳/肛塞/拉珠/阴茎/穿戴式按请求写：施受双方+类型+朝向+可见基部或余段+解剖连贯姿势；**不用日常物替代专用玩具** |
| **L7** | 复杂多人 | 先立每人位置与角色再写共享接触；每人一个主动作；机位能分清肢体归属；不把群交加进单人/双人请求 |

**粗暴叠加层**（可叠在 L3-L6，非默认升级）：紧缚/乳夹/拍打/轻咬抓痕/红印——可见后果止于表面痕迹，不出血、不重伤、不昏迷、不危及生命。

### 强度阶梯与请求档位的对应【权威】

**用户语言映射**：性感/暗示→L1；裸体/全裸→L2；露出/展示→L3；暗示玩法→L4；自慰/外部刺激→L5；插入/性交/口交/后入/骑乘→L6；多人/群交→L7；粗暴/乳夹/拍打→基础档+粗暴叠加。措辞跨档时**取显式请求的最高档，不加别的玩法家族**。

| 请求档位 | 对应阶梯 | 说明 |
|---|---|---|
| A 模式（全年龄向） | 不适用 | 与本阶梯无关 |
| 擦边向 | L1 | 无露点；B 模式下用户明确要求全年龄向表达时也可能落此档 |
| 裸露向 | L2–L3 | 裸体或展露呈现，无性行为接触 |
| 成人向（B 模式默认） | L4–L7 | 涉及玩具接触、插入或多人；**用户不指定时一律落此档** |

- **档位不升不降内容边界**：用户要 explicit 档不代表可以自动加玩具或插入玩法——边界仍由用户显式请求的最高档决定（见 §降档规则）。**直白度授权≠玩法授权**。
- **反向也不软化**：用户显式点名 L5/L6 玩法时，不因为请求档位较低就降成 L3 展示。
- A 模式下本阶梯不适用（限全年龄向）。

**降档规则**：道具是日常易碎/锋利物→改暗示或换专用玩具；接触状态含糊→问一个聚焦问题；机位展示不了该互动→降档；成年不明→按成年底线处理。

## 二、玩法八家族（选一主族 + 至多一个兼容叠加）

选择原则：`主玩法 → 身体状态 → 道具/接触 → 可见反应 → 环境支撑`。兼容叠加（镜子录像/局部着装/湿润/公开可见/合意粗暴）最多叠一个；**不堆叠多个不相关玩法家族**。

| 家族 | 核心要求 |
|---|---|
| 1 暴露展示 | 刻意呈现（开展坐姿/站立揭示/回眸）；遮挡物必须连在手上或面上，禁止悬浮遮挡 |
| 2 单人自慰 | 指明动作的手与接触点；骑行类要写稳定 mounting 面 |
| 3 双人/多人 | 先选一个机械连贯的姿势族（正躺位/后入/骑乘/对坐/站立/侧卧六族）；每个肢体归属到人 |
| 4 拘束展示 | 每个锚点可见、张力方向可读；solo 场景牵绳必须连固定点或躺置可见——**禁止画外持绳人** |
| 5 合意粗暴 | 独立叠加层非默认；可见后果=红印/手印/绳痕 |
| 6 湿润液体 | 一个水源一条因果链；乳/尿系仅显式请求且与无关玩法隔离 |
| 7 情色着装 | 一个可识别的服装机制（内衣/外衣内裸/透明湿衣/角色装），成年身份保持显式 |
| 8 录制视角 | 直摄与反射画面一致；POV 手必须属于在场者；直播不往画面里塞观众 |

## 三、玩具视觉语法（每件主道具答五问）

1. **归属**：谁持/谁戴/谁控？
2. **位置**：在画面哪里、相对身体哪里？
3. **状态**：未用 / 蓄势 / 外部接触 / 佩戴 / 半插入 / 插入？
4. **朝向**：指向哪里、连接什么？
5. **可见结果**：衣物移位/皮肤压痕/姿势张力/震动提示/表情反应？

任一字段答不清 → 简化道具互动。

**接触语言阶梯**（英文措辞梯度）：`resting beside her`（未用）→ `held just above..., angled toward`（蓄势）→ `pressed externally against`（外部）→ `secured beneath the displaced garment`（佩戴）→ 插入态仅在请求时写并显示基部/余段。

**冲突检查**：一手一物一状态；玩具不在手/身/镜/背景重复出现；外部接触措辞不得与完全插入措辞同框；塞物必有可见基部；镣绳必有连接路径；遥控必有配对设备；solo 场景不得出现他人之手；粗暴冲击必有稳定支撑与可见外部目标。

**安全替换**：日常物（食物/瓶/武器/工具）不自动当插入物——换专用玩具或保持物件外部象征（`原生物件 → 合理来源 → 暗示性外部放置 → 手势/视线暗示 → 不加未请求的行为`）。

## 四、prose 骨架模式库（英文句式模板，方括号按用户约束替换）

**通用骨架**：

```text
[Count/identity anchor] [exposure state] [pose] in/on [setting].
[Camera framing, orientation, limb placement, expression, gaze].
[Exact remaining clothing or displaced garment state].
[Hands, anatomy, props, contact points, requested explicit detail].
[Foreground/background establishing location].
[Light source and direction] [highlights, shadows, reflections], creating [atmosphere], rendered as [medium/style].
```

**单人公开暴露**（无旁观者）：地点必须自己证明可见性（open doorway/path/sightline makes discovery plausible; no other person appears）——**不发明窥视者**。

**部分着装**：`The [garment] is [unzipped/pulled down], exposing [region], while [remaining portion] stays around [exact location].` ——有袜/饰/鞋留存时不得写 completely nude。

**湿润裸露**：一个水源（shower/rain/stream/poured）写一条因果链：打湿→贴附→路径→高光收集。

**反射**：镜/玻璃/湿面揭示兼容的第二角度，**不得制造第二个人**；反射内道具与直摄一致。

**拘束**：`[Material] circles [body area] and connects to [anchor], holding [limbs] in [position]. Visible tension causes [compression/posture/displacement].`

**光照模式**：谷仓日光（斜射高光+深处阴影）/ 窗光（frame left 强光+家具投影）/ 暖台灯（局部照脸与躯干）/ 霓虹阳台（湿街反光上色）/ 雨夜灯笼（漫射+橙色点反射）。

**篇幅**：简单单人 80-130 词 / 双人 130-200 / 三人或高密度双人 170-260 / 四人以上 220-320；320 词为常规上限——压缩顺序：合并氛围→删装饰背景→删无关色→删叙事解读→删重复解剖；**保留**计数、暴露态、主姿势、关键接触、公开视线、场景与光源。完整压缩规则见 prose-method.md §篇幅。

**特征中性主体**：用户不要求角色特征时只写 `one character` 或中性计数——不加发色/瞳色/肤色/体型/身份/标志物；姿势、表情、着装态、场景、光是画面属性仍可写。

> 适配说明：源方法论的成人声明尾行（"All characters are adults"）不采用——本 skill 成年底线由 core.md 总则承担（输入归一与拒绝机制），成人数值措辞不进描述正文。
