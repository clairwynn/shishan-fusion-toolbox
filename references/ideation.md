# 构思方法论（画面创意的深化层）

> 生成工作流 A 的上游：要素清单解决"画面缺什么"，本文件解决"画面平庸怎么办"——需求模糊、原创设计、画面没有记忆点时按需读本文件对应节。方法论提炼自公开创作技能体系（GPL，改写适配）。

## 一、记忆点六方向（画面"灵魂"的搜索清单）

想清楚"这张图的灵魂是什么"（tags-techniques 控制意识），从六个方向搜索记忆点：

1. **关系反差**：两个元素的关系违背预期——硬汉叼鲷鱼烧、猛兽配软糯情绪、日常上半身配激烈下半身。
2. **欲望与代价**：想要的东西带着可见的代价（拿了奖品但衣服破了）。
3. **规则的例外**：画面里有一个"不该在"的东西，且它有理由在。
4. **感官与情绪**：把抽象情绪落到具体感官来源（温度、声音痕迹、气味可视化）。
5. **物件母题**：一个贯穿画面的物件承担叙事（信、伞、未拆的礼物）。
6. **形式与视角**：构图本身是内容（极端机位、非常规裁切、镜像结构）。

方案比较的标准：**体验是否变化**——两版提示词只有措辞不同、画面体验相同，就不算两个方案。

## 二、环境设计：空间从生活运行中长出来

- **环境是人格的外化**：同一角色 + 不同环境 = 不同故事；构思时把环境当角色的另一半来选。
- **从运行逻辑长出空间**：先问这个场所怎么运转——入口在哪、东西怎么运进来、人在这里做什么工作、在哪里休息——路径与设施由运行逻辑推出来，而不是罗列"教室有课桌"。
- **痕迹必须有因**：磨损落在常走的边缘、污渍在顺手的位置、维修痕迹对应易损处——痕迹位置错了画面就假。
- **时间与天气改写同一地点**：同一场景在清晨/深夜/雨天是完全不同的画面；先定时刻再定光线。
- **环境有实体铁律**（tag-flow 总则）：至少 3 个环境实体支撑空间，写"那个镇上有什么"而不是"一座欧洲小镇"。

## 三、艺术指导：用观看关系承担情绪

- **情绪不写在情绪词里**，写在观看关系里：距离（远=疏离/近=压迫）、遮挡（谁被挡住=信息差）、空缺（该在而不在的东西）。
- **象征靠关系成立**，不靠图标：乌鸦落在枪上才是象征，单写乌鸦只是鸟。
- **节奏与密度**：画面要有密区与留白区——全画面等密度=没有视觉入口；锁定核心（留白意识，tags-techniques 六意识）。
- **媒介按"表面与边缘"选**：这个题材的质感主要呈现在表面还是边缘（布料在边缘褶皱、金属在表面反射）——据此选媒介词。
- **参考拆解法**：看到好参考图问"去掉角色和题材后剩什么"——剩下的构图/光色/笔触才是可迁移的画风。

## 四、角色设计：核心 → 行为 → 外形

- **角色核心是"能不断生出选择的东西"**：不是一句背景故事，而是一个让角色在任意场景都做得出区别于他人选择的驱动（好胜/怕生/表演欲）。
- **性格翻译成可观察行为**：设计稿里不写"她很谨慎"，写"进门先扫一眼反光面"——行为再翻译成画面可见的姿态与习惯物。
- **外形辨识靠轮廓远读**：把角色涂成剪影仍能认出来——靠轮廓（发型剪影、体型、标志性配件），不靠配色细节。
- **本体不变量与当次变量分层**（consistency.md 三层锚点的构思侧）：设计角色时明确哪些是本体（永远在）、哪些是当次着装（按场景换）——画系列图时不变量不丢、变量自由。

## 五、服装设计：一句命题 + 五维拆解 + 八方法工具箱

- **设计命题**：把服装设计压成一句话（"上班前的居家懒散"）——所有取舍以命题为准。
- **参考板五维拆解**：概念 / 轮廓 / 色彩 / 材质 / 装饰——拆开借鉴，不整套装抄。
- **八方法工具箱**（改造任何基础服装）：

| 方法 | 操作 |
|---|---|
| 异质搭配 | 正装上装 × 运动下装等冲突组合 |
| 跨风格组合 | 一个风格元素移植进另一个风格语境 |
| 结构重组 | 改开合方向、改穿法层次（naked 单件公式、reverse 骨架——见 tags-techniques 服装域） |
| 材质转换 | 同款式换材质（棉→胶衣→蕾丝）画面全变 |
| 比例变化 | 放大/缩小某部件比例（oversized、cropped） |
| 穿法错位 | 正确衣服错误穿法（半脱、只穿一只袖） |
| 图案转译 | 把 A 主题的图案译到 B 载体上 |
| 减法 | 拿掉一件，看画面是否更聚焦 |

- **服装系统六件套**：主体件 + 内层 + 腿部 + 鞋 + 配饰 + 随身物——查漏顺序，不是堆砌要求。
- **出图反馈按层修**：不满意时按 轮廓 → 气质 → 道具 → 携带物 → 主题 的顺序诊断改哪个层，不整版重写。

## 六、构图构思：选择瞬间与分格展示

- **镜头空间主次**：先定"画面第一眼落在哪里"，机位与景别服务这个落点（nl-flow 锚点前置的构思侧）。
- **选择瞬间**：动作写"最有张力的一刻"——递物停在手刚伸到、回头停在头发扬起时（nl-flow 凝固瞬间的选点法）。
- **分格展示**（多视图/设定页/表情集合）：分格不散的关键是**视觉联系**——一张主锚图压阵 + 贯穿色统一 + 实物载体串联（线索板、相册、拍立得摊开）；写法见 nl-flow §角色工作表。
