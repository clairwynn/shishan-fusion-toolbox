# 转换与修改方法论（保意图为纲）

转换 = 把已有提示词在**形态之间**（标签 ↔ 自然语言 ↔ 混合）或**模型之间**（跨语法迁移）换表达，或者按用户要求修改。转换是换表达形态，不是换画面内容。

## 最高原则：保意图

- **补维度，不换主题**：扩写是补全缺失的画面维度；用户说「简单点 / 只要一句」就只出极简版。
- 画面要素、风格、构图、强度在转换前后保持一致；措辞体系可以完全换。
- 用户原串里锁定的内容（角色、比例、暴露程度、人数、排除项）忠实保留——用户点名的主题不软化、不升级、不删减。
- **图串同给**：用户同时给参考图与提示词时，以提示词为转换对象、图作风格与内容参照；两者矛盾时以用户明确意图为准，都不明确则问，不默认图优先或串优先。

## 修改哲学分任务

| 用户说 | 执行哲学 |
|---|---|
| 「只改X / 精确修改 / 把A换成B」 | **逐字冻结**：只动指定范围，其余字符与表示形式原样保留——不顺手删词、加词、排序、标准化空格、修正语法或补模板。字段标签（`UC:`、`Character N:`）也属于要保留的表示形式。**连带改动只列不改**；范围不清先问（如「背景从教室换成海边」——课桌窗户算不算背景，先问）。交付 = 完整原串（只有目标处变化）+ 一行改动清单；交付前逐字比对，清单以外不能有任何差异。 |
| 「优化 / 重写 / 审查 / 精修」 | **主动校验**：检查格式（拼写/顺序/语法体系）、冲突（互斥机位、视线摇摆、双发色无 multicolored hair）、冗余（无作用同义堆叠）、缺项（关键层缺失）。输出 = 修正后的完整提示词 + 问题清单表 `原样 | 修正 | 理由`。没问题的部分不为「看起来改过」而乱动。 |

用户锁定的文字、空格、标点、数值、指定权重与表示形式，在任何模式下照原文保留；**逐字原串优先于写作规范**。

**新元素显式确认**：翻译、等价改写、排序、去重、格式标准化免确认；但**新增任何视觉元素**（新主体/新外观细节/新服装/新动作/新镜头/新光影/新风格/画师）必须显式向用户提出并获同意——**沉默、模糊的请求、"随便改进一下"都不构成批准**。不为显得完整而补用户没要的元素；宁可交付忠实但朴素的版本，附一行"可补充项"清单。

## 权重语法换算（自动换算）

| 源 | 目标 | 换算 |
|---|---|---|
| NAI 旧 `{tag}`（每层≈×1.05） | NAI 数值 | `{{tag}}` ≈ `1.1::tag::`，三层 ≈ `1.16::tag::` |
| NAI 旧 `[tag]`（每层≈×0.95） | NAI 数值 | `[tag]` ≈ `0.95::tag::` |
| NAI 旧 `{}`/`[]` | SD 系 | `{{tag}}`（×1.1025）→ `(tag:1.1)`；`[tag]`（×0.95）→ `[tag:0.9]`——或先归一到数值再换 |
| NAI 数值 `1.2::tag::` | SD 系 | `(tag:1.2)` |
| SD 系 `(tag:1.2)` | NAI 数值 | `1.2::tag::` |
| SD `(tag)`（≈×1.1） | 精确 | `(tag:1.1)` |
| NAI 负权重 `-1::tag::` | SD 系 | 移入负面提示词字段（SD 系无负权重语法，见 models.md §SD 系权重语法）；或按 negative.md 具象化写进正文排除 |
| SD 负面词 | NAI | NAI 的 UC 栏。**注意：NAI 的负权重不进 UC**（见 models.md §NovelAI 权重语法）——UC 与负权重是两套机制，不做二选一 |

换算保留层级结构与打包关系（`{a,b}` 包 → `1.1::a, b::`）。**各模型的有效区间与「无感区」判定一律以 models.md 对应模型节为准**，本文件不重复判定——换算后按目标模型区间复核，落在无感区时提示用户或按目标区间微调并说明。

## 越界权重的处理

参考语料（`database/nsfw/codex/`、`tags-techniques.md`）里存在超出 models.md 声明区间的权重值（如 NAI 声明 1.0–2.0，语料里出现 `2.69::`、`4.02::`）。这些值是**历史存量，不是本skill 的产出规范**。三条处理规则：

- **产出：一律不越界。** 生成的权重必须落在目标模型声明的有效区间内。需要「很强」时用位置前置与措辞强化，不靠超区间数值堆强度。
- **读取：按等效强度理解，不照抄。** 读到越界值时，把它理解为「该概念被要求显著强于默认」，而不是字面上的 4.02 倍。**跨模型迁移时不原样保留该数值**——`4.02::` 迁到 Anima 不会得到同等效果（Anima 需 1.5 起步且无 4档以上语义）。
- **跨模型：对数重标定并声明。** 越界值跨模型时按对数关系重标定到目标区间（不是线性硬乘），并在交付说明里写清「原值 X → 按等效强度重标定为 Y」。无法可靠重标定时，**去掉权重改用位置前置**，并说明为什么去掉。

**数字结尾 tag 紧跟 `::` 会炸串**（`na_tarapisu153::` 被解析成权重 153，整条提示词炸掉）：转换成 NAI 数值语法时遇到数字结尾的 tag，写成 `na_tarapisu153, ::`（加逗号比加空格安全）或拆开处理。

## 拼写与结构转换

- **拼写**：库内下划线形态 ↔ 提示词空格形态互转（`school_uniform` ↔ `school uniform`）；`score_*` 与符号标签（`=_=` 等）保持原样。
- **UC / 负面冲突项：只删不换**——源串中与目标画面冲突的项直接删去（连同后面的逗号空格，加权段不留空位）；不冲突的不删、不自造替代词。
- **人数 tag 去重**：`2girls` 只在主串出现一次；角色栏用单数；多人图的 `extra characters` 排除项删除（单人模板的加权排除段不照抄进多人图）。
- **结构映射**：NAI `Character N:` 多人段 ↔ SD `BREAK` 区域段（Regional Prompter）↔ 无分区的纯 tag 串——转换时把每个角色的外貌组跟随其归属，互动关系在纯 tag 串中改用 `source#/target#` 思路的措辞或从句表达。
- **引号文字**：要画进画面的文字在所有形态中都放引号 + 载体描述；叙事句不加引号。
- **质量前缀与年代词**：按本 skill 规则一律不写——源串里已有的质量前缀在「优化重写」模式下删除并在问题清单注明；「精确修改」模式下原样保留不动。

## 自然语言 → 标签

1. **解析分层**：把句子拆成语义单元，按层归组——人数/主体、角色、外貌、服装、动作姿势、场景、构图镜头、光线、风格、排除。
2. **映射查库**：每个离散语义查 `database/tags/tags.tsv`（模式见 tag-flow.md §库查询（标签的唯一来源））。唯一命中直接用；多候选逐个问用户；库外给最近候选+问，用户指定的原文保留。
3. **关系保留**：空间关系、互动方向、进行中状态等 tag 表达不了的信息——保留为自由英文短语或短句（混合形态），或在纯标签形态中用最接近的 Danbooru 惯用短语（`looking at viewer`、`from side`）。
4. **权重信息**：源句子的强调措辞（"dominates the frame"）转成权重或前置位置，并按目标模型语法落。
5. **组装**：按 tag-flow.md 的顺序拼装；目标模型语法（NAI 数值 / SD 括号 / Anima @artist）按 models.md 落。

## 标签 → 自然语言

1. **分层组句**：把 tag 按层归组后译写进统一骨架（主体与关键特征 → 动作 → 外貌 → 服装材质 → 场景氛围 → 镜头光线 → 风格），句式模板见 nl-flow.md。
2. **权重转措辞**：`(rain:1.3)` 的强调转成句子里的位置前置或措辞强化（"rain streaks heavily through the air"）；NL 流无权重语法（MJ 尾参除外）。
3. **tag 丢形不失义**：`cowboy shot` → `framed from the knees up`；`blush, flying sweatdrop` → `cheeks flushed, a nervous sweatdrop on her temple`——写"能念给人听"的完整句。
4. **画面唯一**：句组与原 tag 串指向同一画面，无新增元素、无丢失主体。
5. **模型收尾**：MJ 附尾参（`--ar 2:3 --niji 6`）；Flux/Nano Banana/GPT-Image 不加尾参；即梦/可灵/Seedream 用中文同结构；Krea 一段连贯中文（见 models.md）。

## 交付

- 转换/修改成品放代码块；「精确修改」附一行改动清单；「优化重写」附问题清单表。
- 交付前逐字比对：改动范围之外零差异（精确修改）。
- 其余按 SKILL.md §五 输出契约执行（单形态、无来源、负面默认不给、参数永不给）。

## 自审（内部完成）

1. 画面要素前后一致（主体/人数/风格/构图/强度无漂移）。
2. 权重换算正确、落在目标模型有效区间、数字结尾 tag 已处理。
3. 目标模型语法体系正确（括号方向、::闭合、@artist、BREAK 分区）。
4. 精确修改零越界；优化重写的问题清单覆盖所有实际改动。
5. 无来源痕迹、无质量前缀、无年代词（精确修改的源串原有项除外——原样保留）。
